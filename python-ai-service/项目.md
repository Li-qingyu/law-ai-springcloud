# 法律咨询AI服务项目

## 项目概述

这是一个基于RAG（检索增强生成）架构的法律咨询AI服务，提供智能法律问答、管理员数据管理等功能。

## 已完成功能

### 1. AI法律咨询功能
- **智能法律问答**：基于RAG架构，结合法律条文、案例和历史咨询进行回答
- **流式/非流式回答**：支持SSE流式输出和普通JSON响应
- **语义缓存**：相似问题直接返回缓存结果，提高响应速度
- **对话记忆管理**：
  - 工作记忆：保留最近2-3轮对话
  - 短期记忆：会话内摘要，12小时TTL
  - 长期记忆：跨会话语义检索
- **意图分类**：自动识别简单查询、咨询、追问、闲聊等意图
- **代词消解**：自动将代词替换为具体实体

### 2. 管理员功能
- **数据管理**：法律条文、案例、咨询历史的增删改查
- **文件管理**：文件上传、下载、删除
- **日志管理**：操作日志查询和分析
- **权限管理**：用户角色和权限控制
- **路由工作流**：基于LangGraph的意图分类和权限检查

### 3. 检索优化
- **向量检索**：基于Milvus的语义相似度检索
- **混合检索**：向量 + BM25关键词检索
- **多路改写**：LLM改写查询，提高召回率
- **重排序**：DashScope重排序模型，提高准确率

### 4. API接口
- `POST /v1/ai/consult`：非流式AI咨询
- `POST /v1/ai/consult/stream`：流式AI咨询（SSE）
- `GET /v1/ai/health`：健康检查
- `POST /v1/ai/cache/cleanup`：手动清理过期缓存
- `POST /admin/manage`：管理员统一管理接口
- `POST /admin/manage/confirm`：删除操作确认接口
- `POST /admin/manage/stream`：管理员流式管理接口

## 技术栈

- **Web框架**：FastAPI
- **AI框架**：LangChain + LangGraph
- **向量数据库**：Milvus
- **缓存**：Redis
- **LLM模型**：通义千问（qwen-plus）、DeepSeek
- **嵌入模型**：text-embedding-v3
- **包管理**：uv

## 启动项目步骤

### 1. 环境准备

```bash
# 确保Python版本 >= 3.13
python --version

# 安装uv包管理器（如果未安装）
pip install uv
```

### 2. 安装依赖

```bash
# 进入项目目录
cd python-ai-service

# 安装依赖
uv sync
```

### 3. 配置环境变量

创建或修改 `.env` 文件，配置以下环境变量：

```env
# 应用基础配置
DEBUG=True

# 服务配置
SERVICE_HOST=0.0.0.0
SERVICE_PORT=8000

# AI模型配置（通义千问）
DASHSCOPE_API_KEY=your_dashscope_api_key
OPENAI_MODEL=qwen-plus

# 嵌入模型配置
EMBEDDING_MODEL=text-embedding-v3
EMBEDDING_DIMENSION=1024

# DeepSeek模型配置
DEEPSEEK_API_KEY=your_deepseek_api_key
DEEPSEEK_MODEL=deepseek-v4-flash
DEEPSEEK_API_BASE_URL=https://api.deepseek.com/v1

# Milvus向量数据库配置
MILVUS_HOST=localhost
MILVUS_PORT=19530
MILVUS_DATABASE_NAME=law_ai
MILVUS_COLLECTION_ARTICLES=law_articles
MILVUS_COLLECTION_CASES=law_cases
MILVUS_COLLECTION_HISTORY=consult_history
MILVUS_METRIC_TYPE=COSINE

# Redis缓存配置
REDIS_HOST=localhost
REDIS_PORT=6379
REDIS_DB=2
REDIS_PASSWORD=
REDIS_EXPIRE_TIME=86400

# MySQL数据库配置（可选）
DB_HOST=localhost
DB_PORT=3306
DB_USERNAME=root
DB_PASSWORD=your_password
DB_DATABASE_NAME=law_consultation

# Agent配置
AGENT_MAX_ITERATIONS=10
TOOL_SCORE_THRESHOLD=0.63
TOP_K_RESULTS=5
```

### 4. 启动依赖服务

```bash
# 启动Milvus向量数据库（需要Docker）
docker run -d --name milvus \
  -p 19530:19530 \
  -p 9091:9091 \
  -v /path/to/milvus/data:/var/lib/milvus \
  milvusdb/milvus:latest

# 启动Redis缓存
docker run -d --name redis \
  -p 6379:6379 \
  redis:latest

# 启动MySQL数据库（可选）
docker run -d --name mysql \
  -p 3306:3306 \
  -e MYSQL_ROOT_PASSWORD=your_password \
  -e MYSQL_DATABASE=law_consultation \
  mysql:latest
```

### 5. 启动项目

```bash
# 开发模式启动（自动重载）
uv run uvicorn app.main:app --reload

# 或者指定主机和端口
uv run uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload

# 生产模式启动
uv run uvicorn app.main:app --host 0.0.0.0 --port 8000 --workers 4
```

### 6. 访问服务

- **API文档**：http://localhost:8000/docs
- **健康检查**：http://localhost:8000/v1/ai/health
- **AI咨询接口**：http://localhost:8000/v1/ai/consult
- **流式咨询接口**：http://localhost:8000/v1/ai/consult/stream

## 注意事项

1. **API密钥安全**：不要将真实的API密钥提交到版本控制系统
2. **服务依赖**：确保Milvus、Redis等服务正常运行
3. **Python版本**：需要Python 3.13或更高版本
4. **内存要求**：LLM模型和向量数据库需要较大内存
5. **网络访问**：需要访问通义千问和DeepSeek的API服务
