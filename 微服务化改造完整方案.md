## 一、项目概述

### 1.1 当前架构

- **架构类型**：单体 Spring Boot 应用
- **Spring Boot 版本**：3.5.11
- **Java 版本**：17
- **模块结构**：
  - `law-ai-pojo`：实体类、DTO、VO、异常类
  - `law-ai-service`：业务逻辑、控制器、服务实现

### 1.2 目标架构

```
law-consultant-microservice/          # 新仓库（微服务版）
├── law-common/                       # 公共模块
│   ├── law-common-core/              # 核心工具类
│   ├── law-common-redis/             # Redis 工具
│   ├── law-common-security/          # JWT 安全工具
│   └── law-common-oss/               # OSS 工具
├── law-gateway/                      # API 网关 (端口: 80)
├── law-user-service/                 # 用户服务 (端口: 8081)
├── law-law-service/                  # 法典服务 (端口: 8082)
├── law-ai-service/                   # AI 服务 (端口: 8083)
└── law-common-service/               # 通用服务 (端口: 8084)
```

### 1.3 技术栈版本

| 组件 | 版本 | 说明 |
|------|------|------|
| Spring Boot | 3.5.11 | 保持与原项目一致 |
| Spring Cloud | 2023.0.1 | 与 Boot 3.x 兼容 |
| Spring Cloud Alibaba | 2023.0.1.0 | Nacos、Sentinel 等 |
| Nacos | 2.3.x | 注册中心 + 配置中心 |
| Java | 17 | 保持与原项目一致 |

## 三、公共模块设计

### 3.1 模块职责划分

| 模块 | 职责 | 包含内容 |
|------|------|----------|
| law-common-core | 核心基础类 | Result、BaseException、GlobalExceptionHandler、实体类、DTO、VO |
| law-common-redis | Redis 工具 | RedisConfig、RedisUtil |
| law-common-security | 安全工具 | JwtUtil、JwtTokenInterceptor、JwtProperties |
| law-common-oss | OSS 工具 | AliOssUtil、AliOssProperties |

### 3.2 依赖引入方式

各微服务按需引入公共模块：

```xml
<!-- law-user-service/pom.xml -->
<dependencies>
    <!-- 核心模块（必需） -->
    <dependency>
        <groupId>org.law</groupId>
        <artifactId>law-common-core</artifactId>
        <version>1.0.0-SNAPSHOT</version>
    </dependency>
    
    <!-- 安全模块（需要 JWT 功能时） -->
    <dependency>
        <groupId>org.law</groupId>
        <artifactId>law-common-security</artifactId>
        <version>1.0.0-SNAPSHOT</version>
    </dependency>
    
    <!-- Redis 模块（需要 Redis 时） -->
    <dependency>
        <groupId>org.law</groupId>
        <artifactId>law-common-redis</artifactId>
        <version>1.0.0-SNAPSHOT</version>
    </dependency>
    
    <!-- OSS 模块（需要文件上传时） -->
    <dependency>
        <groupId>org.law</groupId>
        <artifactId>law-common-oss</artifactId>
        <version>1.0.0-SNAPSHOT</version>
    </dependency>
</dependencies>
```

### 3.3 各服务依赖对照表

| 服务 | 必需模块 | 可选模块 |

| law-user-service | law-common-core, law-common-security, law-common-redis | - |

## 四、自动配置机制

### 4.1 什么是自动配置

Spring Boot 的自动配置机制允许在引入 jar 包依赖后，自动加载其中定义的 Bean，无需手动添加 `@ComponentScan`。

### 4.2 实现步骤

#### 步骤 1：创建自动配置类

**示例：law-common-security 模块**

```java
package org.law.common.security.config;

import org.law.common.security.interceptor.JwtTokenInterceptor;
import org.law.common.security.properties.JwtProperties;
import org.law.common.security.utils.JwtUtil;
import org.springframework.boot.context.properties.EnableConfigurationProperties;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.ComponentScan;
import org.springframework.context.annotation.Configuration;

@Configuration
@ComponentScan(basePackages = "org.law.common.security")
@EnableConfigurationProperties(JwtProperties.class)
public class SecurityAutoConfiguration {

    @Bean
    public JwtUtil jwtUtil() {
        return new JwtUtil();
    }

    @Bean
    public JwtTokenInterceptor jwtTokenInterceptor() {
        return new JwtTokenInterceptor();
    }
}
```

#### 步骤 2：创建 spring.factories 文件

**文件位置**：`src/main/resources/META-INF/spring.factories`

```properties
# Auto Configure
org.springframework.boot.autoconfigure.EnableAutoConfiguration=\
org.law.common.security.config.SecurityAutoConfiguration
```

#### 步骤 3：各模块 spring.factories 配置

**law-common-core**：
```properties
org.springframework.boot.autoconfigure.EnableAutoConfiguration=\
org.law.common.core.config.CoreAutoConfiguration
```

**law-common-redis**：
```properties
org.springframework.boot.autoconfigure.EnableAutoConfiguration=\
org.law.common.redis.config.RedisAutoConfiguration
```

**law-common-oss**：
```properties
org.springframework.boot.autoconfigure.EnableAutoConfiguration=\
org.law.common.oss.config.OssAutoConfiguration
```

### 4.3 使用自动配置后各服务启动类

```java
package org.law.user;

import org.mybatis.spring.annotation.MapperScan;
import org.springframework.boot.SpringApplication;
import org.springframework.boot.autoconfigure.SpringBootApplication;
import org.springframework.cloud.client.discovery.EnableDiscoveryClient;

@SpringBootApplication
@EnableDiscoveryClient
@MapperScan("org.law.user.mapper")
// 不需要 @ComponentScan，自动配置会自动加载
public class UserServiceApplication {
    public static void main(String[] args) {
        SpringApplication.run(UserServiceApplication.class, args);
    }
}
```

### 4.4 条件装配

使用 `@Conditional` 注解实现条件装配：

```java
@Configuration
@ConditionalOnClass(name = "io.jsonwebtoken.Jwts")  // 只有引入 jjwt 依赖时才生效
@ComponentScan(basePackages = "org.law.common.security")
@EnableConfigurationProperties(JwtProperties.class)
public class SecurityAutoConfiguration {

    @Bean
    @ConditionalOnMissingBean(JwtUtil.class)  // 如果没有 JwtUtil Bean 才创建
    public JwtUtil jwtUtil() {
        return new JwtUtil();
    }
}
```

### 4.5 Spring Boot 3.x 新方式

**文件位置**：`src/main/resources/META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports`

```
org.law.common.core.config.CoreAutoConfiguration
org.law.common.security.config.SecurityAutoConfiguration
org.law.common.redis.config.RedisAutoConfiguration
org.law.common.oss.config.OssAutoConfiguration
```

### 7.1 @ConfigurationProperties 使用

**属性类定义**：

```java
package org.law.common.security.properties;

import lombok.Data;
import org.springframework.boot.context.properties.ConfigurationProperties;
import org.springframework.stereotype.Component;

@Data
@Component
@ConfigurationProperties(prefix = "law.jwt")

    private String adminSecretKey = "lawai";
    private Long adminTtl = 864000000L;
    private String adminTokenName = "token";
}
```

**在工具类中使用**：

```java
package org.law.common.security.utils;

import org.law.common.security.properties.JwtProperties;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.stereotype.Component;

@Component
public class JwtUtil {

    @Autowired
    private JwtProperties jwtProperties;

    public String generateToken(Long userId) {
        return Jwts.builder()
                .setSubject(String.valueOf(userId))
                .setExpiration(new Date(System.currentTimeMillis() + jwtProperties.getAdminTtl()))
                .signWith(SignatureAlgorithm.HS256, jwtProperties.getAdminSecretKey())
                .compact();
    }
}
```

## 九、常见问题解决

### 9.1 Bean 未找到异常

**问题**：`No qualifying bean of type 'org.law.common.security.utils.JwtUtil'`

**解决**：
1. 检查 `spring.factories` 是否正确配置
2. 检查自动配置类的 `@ComponentScan` 是否正确
3. 确认依赖已正确引入

### 9.2 配置属性未绑定

**问题**：`jwtProperties.getAdminSecretKey()` 返回 null

**解决**：
1. 检查 `@ConfigurationProperties(prefix = "law.jwt")` 前缀是否正确
2. 检查 Nacos 配置文件中的配置结构是否匹配
3. 确保 `shared-configs` 中已引用对应配置文件

### 9.3 Nacos 配置未生效

**问题**：修改 Nacos 配置后，服务未获取到新配置

**解决**：
1. 检查 `shared-configs` 中的 `data-id` 是否正确
2. 检查 `group` 是否匹配
3. 检查 `namespace` 是否正确
4. 确保 `refresh: true` 已设置

### 9.4 Feign 调用失败

**问题**：`FeignException$MethodNotFoundException`

**解决**：
1. 检查 `@FeignClient(name = "xxx")` 的 name 是否与被调用方一致
2. 检查接口路径是否匹配
3. 检查参数名称是否一致

## 十、总结

### 10.1 配置管理最佳实践

1. **分离配置**
   - 公共配置放 `common.yml`
   - 模块专属配置放 `common-xxx.yml`
   - 服务专属配置放 `law-xxx-service.yml`

2. **敏感信息管理**
   - 使用环境变量：`${ENV_VAR:default}`
   - 生产环境使用加密配置

3. **配置热更新**
   - 共享配置设置 `refresh: true`
   - 使用 `@ConfigurationProperties` 自动支持热更新

4. **环境隔离**
   - 使用命名空间隔离环境
   - 使用分组组织配置

### 10.2 配置文件清单

| 文件 | 位置 | 用途 |
|------|------|------|
| bootstrap.yml | 各服务 resources/ | 连接 Nacos 配置中心 |
| application.yml | 各服务 resources/ | 本地配置（可选） |
| common.yml | Nacos 配置中心 | 公共配置 |
| common-security.yml | Nacos 配置中心 | 安全模块配置 |
| common-oss.yml | Nacos 配置中心 | OSS 模块配置 |
| law-xxx-service.yml | Nacos 配置中心 | 各服务专属配置 |
