## 七、关键技术决策

1. **Java 代理 Python AI 服务**：网关 → ai-service → Python，统一鉴权、服务治理、限流降级
2. **Nacos 配置中心**：数据库连接等敏感配置外置，服务只保留自身名称和 Nacos 连接信息
3. **Milvus 混合检索**：dense vector + BM25 结合，兼顾语义相似度与关键词匹配；通过配置开关控制是否启用混合检索、多路改写、重排序
4. **LangGraph 多 Agent**：Router/File/Data/Log/Permission 五子 Agent 协同，支持自然语言后台管理；使用 interrupt/resume 实现人机交互确认
5. **Memory 系统**：工作记忆/短期记忆/长期记忆三级，隐私脱敏后持久化到 Redis
6. **语义缓存**：基于 Milvus 的 SemanticCache，相似度 > 0.95 直接返回缓存，0.85~0.95 返回缓存并标记后台刷新，减少重复查询的 LLM 开销
7. **双模型支持**：通义千问（DashScope）+ DeepSeek 双模型，通过配置切换，支持不同场景的性能/成本平衡
